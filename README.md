# Briefly

Briefly is a free Mac app that rewrites PDF, Word, text and Markdown documents at the length and reading level you choose. Everything runs on your Mac using Apple Intelligence, so your documents never leave your computer.

This repository holds the app's public web pages, served with GitHub Pages:

- [Support](https://andrewcparnell.github.io/Briefly/support.html)
- [Privacy policy](https://andrewcparnell.github.io/Briefly/privacy.html)
